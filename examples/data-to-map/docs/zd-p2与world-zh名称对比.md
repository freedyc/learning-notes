# zd-p2.csv 与 world-zh.json 名称对比分析

## 为什么地图不能展示？

ECharts 地图通过 **名称精确匹配** 来给区域上色：数据里的 `name` 必须等于 GeoJSON 里 `properties.name`。  
zd-p2.csv 里很多是**简称/俗称**，而 world-zh.json 里是**标准中文名**，不一致就无法匹配，地图上就不会显示颜色。

## 名称差异对照表

| zd-p2.csv 中的名称 | world-zh.json 中的 name | 是否匹配 |
|-------------------|--------------------------|----------|
| 沙特 | **沙特阿拉伯** | ❌ 需映射 |
| 塔吉克 | **塔吉克斯坦** | ❌ 需映射 |
| 印尼 | **印度尼西亚** | ❌ 需映射 |
| 所罗门 | **所罗门群岛** | ❌ 需映射 |
| 孟加拉 | **孟加拉国** | ❌ 需映射 |
| 刚果 | **刚果（布）** / **刚果（金）** | ❌ 需映射（地图有两块，常用刚果（金）） |
| 多国 | （无对应区域） | ❌ 无法展示 |
| 哥伦比亚、南非、泰国、越南、伊拉克… | 与 world-zh 一致 | ✅ 可直接匹配 |

## world-zh.json 的命名规则

- 每个 Feature 的 `properties` 里有：
  - **name**：简短中文名（地图匹配用这个）
  - **full_name**：完整国名，如「沙特阿拉伯王国」
  - **iso_a2 / iso_a3 / iso_n3**：ISO 国家代码

- 数据文件里的「区域名称」列必须和 **name** 完全一致（或通过代码映射到 name），才能正确上色。

## 解决方案

在代码中为世界地图增加**常用简称 → 标准 name** 的映射表，将 CSV 里的「沙特、塔吉克、印尼、所罗门、孟加拉、刚果」等转换为 world-zh.json 中的 name，地图即可正常展示。
